# Pizarra Políglota

Escribe o dicta una frase en español y proyéctala a pantalla completa traducida a todos los idiomas de la clase a la vez. Pensada para clases de español con alumnos de muchas nacionalidades.

**Abrir:** https://palexandre.github.io/pizarra-poliglota/

## Uso

1. Elige los idiomas de la clase (hay más de 140, con buscador).
2. Escribe la frase o pulsa **Dictar**.
3. Pulsa **Proyectar** o `Ctrl + Enter`.

En la proyección: `Esc` vuelve, `←` `→` cambian de página y `Espacio` pausa el paso automático.

La configuración, las frases recientes y las traducciones ya hechas se guardan en el navegador.

## Notas

- Es un único archivo `index.html`, sin dependencias ni servidor.
- Traduce con el traductor de Google y, si falla, con MyMemory. Opcionalmente se puede poner una clave de Google Cloud Translation en Ajustes.
- El dictado funciona en Chrome y Edge.
